Common questions

The app won't pair with the admin desktop.
Make sure both devices are on the same WiFi network, and that the QR code shown on the admin desktop hasn't expired — scan a fresh one from the admin device if needed.

My connection keeps dropping.
Command.Crew automatically reconnects for up to 2 minutes if the network drops. If it doesn't recover, re-pair using the QR code on the admin desktop.
